# Contributing

This is a small, one-person project built with an AI pair-programmer. Issues and pull requests are welcome.

- **Discuss big changes first.** Open an issue before a large rewrite or a new system. Small fixes can go straight to a pull request.
- **Edit `src/`, not `index.html`.** `index.html` and `sw.js` are generated by `python3 build.py`.
- **Run the tests.** After building, open `tests/runner.html` in a browser. All tests should pass. Add a test for a bug you fix.
- **Keep it offline.** No accounts, servers, analytics, API keys or network calls. Never commit secrets.
- **Keep the voice.** The System speaks coldly and formally: short, neutral, never cute or insulting.
- **Saves are sacred.** Any new saved field goes into `sanitize()` and a migration step in `src/core/save.js`, with `SAVE_VERSION` bumped.
- **Licensing.** Contributions are under GPL-3.0-or-later. Do not add copied art, names or assets from other works.
